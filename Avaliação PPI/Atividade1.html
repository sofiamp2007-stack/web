O que é HTML e qual é seu papel dentro da Web ?

HTML é uma linguagem de marcação, um código que cria um documento, com escrita, imagens, links, entre outras coisas, e é exibido em forma de página dentro da web.

Na web o HTML é responsável por definir a organização do conteúdo que os usuários veem na página. A web utiliza o protocolo HTTP na comunicação servidor-cliente e para que essa informação seja exibida ao cliente é preciso a linguagem de marcação HTML que vai exibir os dados em uma página visível no navegador.

Tipos de conteúdo que podem estar contidos dentro de um documento html:

  • Textos
  • imagens
  • Links
  • Formulários
  • Tabelas
