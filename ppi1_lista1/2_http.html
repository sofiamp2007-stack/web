O que é protocolo HTTP?

O HTTP é um protocolo usado na comunicação cliente servidor. Um programa solicita algo ao servidor que responde de acordo com a programação e a linguagem utilizada nessa comunicação é chamada de protocolo.

Como é usado na web?

Quando um usuário (como um navegador) faz uma solcitação (request) a um servidor pedindo um recurso, como uma página, é enviada uma requisição HTTP. O servidor processa a mensagem e gera uma resposta(response) texto de retorno, que pode exibir o conteúdo da página.

Exemplo de Requisição

Requisição (Request)
É um pedido que o navegador faz ao servidor, como: "Me manda essa página".
Tipos de requisição
GET (buscar dados), POST (enviar dados), PUT (atualizar), DELETE (remover).
